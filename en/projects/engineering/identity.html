FLAGSHIP PROJECT · HSE-02 + HSE-05

Identity & Secure Access Engineering

Build a Zero Trust access design with Conditional Access test scenarios and a least-privilege read-only Graph audit.

PlannedNo HSE execution evidence yet
01

Security challenge

Unintended access may arise from policy scope, exclusions, unmanaged devices or overbroad identity permissions.

02

Proposed approach

Create an access-decision matrix, use What If and report-only analysis where available, then design a least-privilege Graph audit.

03

Validation plan (not performed)

Positive test
Five predefined access scenarios are explained and assessed with the selected method.
Negative test
An excluded or unmanaged device and insufficient Graph permissions produce the expected boundary outcome or safe error.
Required evidence
Access matrix, policy impact, sanitized read-only audit, error handling and emergency access plan.
04

Evidence boundaries

What If predicts policy behavior; real access enforcement requires a separately authorized sign-in test.

These are acceptance criteria, not observed test results.

CURRENT STATE

Planned · not started

PREREQUISITES

SC-300 fundamentals, suitable licenses, test accounts and separate approval before policy enforcement.

PUBLICATION GATE

Private lab evidence requires human review and sanitization before public release.
