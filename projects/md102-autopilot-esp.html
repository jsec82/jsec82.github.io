01

Approach and tools

Inspected Autopilot profile targeting, enrollment restrictions and ESP settings. Completed user-driven Windows setup, signed in with the selected lab account and verified local device trust and MDM indicators.

02

Evidence and validation

On 3 November 2026, the user observed AzureAdJoined = YES, DomainJoined = NO and AzureAdPrt = YES via dsregcmd. The Windows device appeared in Intune with Managed by = Microsoft Intune. These confirm Entra join, user SSO readiness and Intune MDM visibility. ESP completion has not been established.

03

Result and limitations

Core Microsoft Entra join and Intune MDM enrollment confirmed by user observation. Effective compliance and configuration policy outcomes, application enforcement and actual ESP result remain to be tested.

04

Lessons learned

Validate the device trust state, user PRT and MDM status separately. A reachable desktop alone is insufficient; policy application requires additional per-device verification.
